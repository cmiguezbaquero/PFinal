### 📦 Modelos (7 entidades)

```
USER (usuario registrado)
├─ id, email, password (hasheada)
├─ name
├─ goalType, level, trainingDaysPerWeek
└─ hasGoals (flag)

ROUTINE (plan semanal)
├─ id, name, weekStart
├─ autoGenerated (si es del sistema)
└─ workouts (N)

WORKOUT (sesión diaria)
├─ id, description, plannedDate
├─ completed, completedAt
└─ exercises (N)

WORKOUTEXERCISE (ejercicio dentro sesión)
├─ exercise (referencia)
├─ sets, reps, weight

EXERCISE (catálogo global + personal)
├─ name, muscleGroup, description
├─ ownerId (null = global)
└─ shared (bool)

WORKOUTSESSION (histórico/notas)
├─ id, date, notes
└─ workout (referencia)

GOAL (para Fase B, no se usa en A)
```

```

  POST /api/auth/register     → Crear usuario

PROGRESO
  GET  /api/sessions/compliance/user/{id}/week/{weekStart}  → % cumplimiento
```

## 🔐 SEGURIDAD (Fase A)

### Auth
- Email + Password
- Hash PBKDF2 (65536 iteraciones)
- Validación timing-safe (protege contra timing attacks)

### Validaciones
- Email único en BD
- Password mínimo 6 caracteres
- Campos requeridos
- Tipos de datos validados

### Respuestas
- Nunca devuelve password
- Error genérico si credenciales fallan
- No revela si existe el usuario

- JWT tokens
- Refresh tokens
- HttpOnly cookies

## 📋 FLUJO USUARIO (Paso a paso)

### 1️⃣ REGISTRO
```
Usuario ve: /users/users.html
├─ Form: name, email, password
└─ Click: [Register]
  ├─ Valida: email no vacío, password 6+ chars
  ├─ Backend: hashea password (PBKDF2)
  ├─ Guarda en BD
  └─ Devuelve: {id, name, email, hasGoals=false, ...}
    └─ Frontend: LocalStorage.setCurrentUser(user)
      └─ Redirige: /goals/goals.html
```

### 2️⃣ LOGIN
```
Usuario ve: /users/users.html
├─ Form: email, password
└─ Click: [Login]
  ├─ Backend: busca usuario por email
  ├─ Valida password (timing-safe)
  ├─ Si OK: devuelve {id, name, email, ...}
  ├─ Si NO: error "Invalid credentials"
  └─ Frontend: LocalStorage.setCurrentUser(user)
    └─ Redirige: /goals/goals.html O /home/home.html
```

### 3️⃣ CONFIGURAR OBJETIVOS
```
Usuario ve: /goals/goals.html
├─ Form: goalType (gain_muscle, lose_weight)
│       level (beginner, intermediate, advanced)
│       trainingDaysPerWeek (1-7)
└─ Click: [Save & Generate Routine]
  ├─ PUT /api/users/{id}/goals → Guarda objetivos
  ├─ Actualiza User.hasGoals = true
  ├─ POST /api/routines/weekly/generate
  │  └─ Crea 4-5 workouts automáticos
  │     ├─ Elige ejercicios del catálogo
  │     ├─ Sets/reps según goalType
  │     └─ Weight según level
  └─ Redirige: /home/home.html
```

### 4️⃣ VER RUTINA & PROGRESO
```
Usuario ve: /home/home.html (Dashboard)
├─ Muestra:
│  ├─ Welcome {name}
│  ├─ Active Plans: N
│  ├─ Weekly Workouts: N
│  └─ Compliance: 3/4 (75%)
└─ Click: [View Full Routine]
  ├─ Redirige: /workouts/workouts.html
  ├─ Muestra tabla con:
  │  ├─ Día | Sesión | Ejercicios | [✓ Completado]
  │  └─ Al marcar: PUT /api/workouts/{id}/mark-completed
  └─ Actualiza progress bar
```
