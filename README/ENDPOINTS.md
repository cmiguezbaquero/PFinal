# 🔌 ENDPOINTS API - Workout Planner

## 📌 BASE URL
```
http://localhost:8080/api
```

---

## 🔐 AUTENTICACIÓN (Auth)

### 1. Registro
```
POST /auth/register
Content-Type: application/json

{
  "name": "Carolina",
  "email": "carolina@example.com",
  "password": "SecurePass123"
}

RESPONSE (201 Created):
{
  "id": 1,
  "name": "Carolina",
  "email": "carolina@example.com",
  "hasGoals": false,
  "goalType": null,
  "level": null,
  "trainingDaysPerWeek": 0
}
```

### 2. Login
```
POST /auth/login
Content-Type: application/json

{
  "email": "carolina@example.com",
  "password": "SecurePass123"
}

RESPONSE (200 OK):
{
  "id": 1,
  "name": "Carolina",
  "email": "carolina@example.com",
  "hasGoals": false,
  "goalType": null,
  "level": null,
  "trainingDaysPerWeek": 0
}

ERROR (401 Unauthorized):
{
  "status": 401,
  "error": "Unauthorized",
  "message": "Invalid credentials"
}
```

## 👤 USUARIOS (Users)

### 1. Obtener usuario por ID
```
GET /users/{id}

RESPONSE (200 OK):
{
  "id": 1,
  "name": "Carolina",
  "email": "carolina@example.com",
  "hasGoals": true,
  "goalType": "gain_muscle",
  "level": "intermediate",
  "trainingDaysPerWeek": 4
}
```

### 2. Actualizar datos usuario
```
PUT /users/{id}
Content-Type: application/json

{
  "name": "Carolina Updated",
  "email": "carolina.new@example.com",
  "password": "NewPassword456"  ← opcional
}

RESPONSE (200 OK): User actualizado
```

### 3. Actualizar objetivos
```
PUT /users/{id}/goals
Content-Type: application/json

{
  "goalType": "gain_muscle",      ← required: "gain_muscle" | "lose_weight"
  "level": "intermediate",         ← required: "beginner" | "intermediate" | "advanced"
  "trainingDaysPerWeek": 4         ← required: 1-7
}

RESPONSE (200 OK):
{
  "id": 1,
  "name": "Carolina",
  "email": "carolina@example.com",
  "hasGoals": true,
  "goalType": "gain_muscle",
  "level": "intermediate",
  "trainingDaysPerWeek": 4
}

ERROR (400 Bad Request):
{
  "status": 400,
  "error": "Bad Request",
  "message": "Goal type is required"
}
```

### 4. Obtener todos los usuarios
```
GET /users

RESPONSE (200 OK):
[
  { id: 1, name: "Carolina", ... },
  { id: 2, name: "Ana", ... }
]
```

### 5. Eliminar usuario
```
DELETE /users/{id}

RESPONSE (204 No Content)
```

## 📋 RUTINAS (Routines)

### 1. Generar rutina semanal automática
```
POST /routines/weekly/generate
Content-Type: application/json

{
  "userId": 1,
  "weekStart": "2024-04-22"  ← formato: YYYY-MM-DD (lunes de la semana)
}

RESPONSE (201 Created):
{
  "id": 10,
  "name": "Weekly plan 2024-04-22",
  "description": "Auto-generated routine",
  "weekStart": "2024-04-22",
  "autoGenerated": true,
  "user": { "id": 1, ... },
  "workouts": [
    {
      "id": 20,
      "description": "Session 1",
      "plannedDate": "2024-04-22",
      "completed": false,
      "exercises": [
        {
          "id": 1,
          "exercise": { "id": 5, "name": "Bench Press", ... },
          "sets": 4,
          "reps": 10,
          "weight": 20.0
        },
        ...
      ]
    },
    { id: 21, ... },
    { id: 22, ... }
  ]
}

ERROR (400 Bad Request):
- "weekStart is required"
- "trainingDaysPerWeek must be between 1 and 7"
- "No exercises available"
```

### 2. Obtener rutinas de usuario
```
GET /routines/user/{userId}

RESPONSE (200 OK):
[
  {
    "id": 10,
    "name": "Weekly plan 2024-04-22",
    "weekStart": "2024-04-22",
    "autoGenerated": true,
    "workouts": [...]
  },
  { id: 11, ... }
]
```

### 3. Obtener rutina por ID
```
GET /routines/{id}

RESPONSE (200 OK):
{
  "id": 10,
  "name": "Weekly plan 2024-04-22",
  "workouts": [...]
}
```

### 4. Actualizar rutina
```
PUT /routines/{id}
Content-Type: application/json

{
  "name": "My Custom Plan",
  "description": "Modified routine",
  "weekStart": "2024-04-22",
  "autoGenerated": false
}

RESPONSE (200 OK): Routine actualizado
```

### 5. Eliminar rutina
```
DELETE /routines/{id}

RESPONSE (204 No Content)
```

## 💪 WORKOUTS (Sesiones de Entrenamiento)

### 1. Obtener workouts de usuario en una semana
```
GET /workouts/user/{userId}/week/{weekStart}
← weekStart formato: YYYY-MM-DD

RESPONSE (200 OK):
[
  {
    "id": 20,
    "description": "Session 1",
    "plannedDate": "2024-04-22",
    "completed": false,
    "completedAt": null,
    "exercises": [
      {
        "id": 1,
        "exercise": {
          "id": 5,
          "name": "Bench Press",
          "muscleGroup": "chest",
          "description": "Push weight up"
        },
        "sets": 4,
        "reps": 10,
        "weight": 20.0
      }
    ]
  },
  ...
]
```

### 2. Obtener todos los workouts de usuario
```
GET /workouts/user/{userId}

RESPONSE (200 OK):
[{ id: 20, ... }, { id: 21, ... }, ...]
```

### 3. Obtener workout por ID
```
GET /workouts/{id}

RESPONSE (200 OK):
{
  "id": 20,
  "description": "Session 1",
  "plannedDate": "2024-04-22",
  "completed": false,
  "exercises": [...]
}
```

### 4. Marcar workout como completado
```
PUT /workouts/{id}/mark-completed
Content-Type: application/json

{
  "completed": true
}

RESPONSE (200 OK):
{
  "id": 20,
  "description": "Session 1",
  "completed": true,
  "completedAt": "2024-04-22"
}
```

### 5. Actualizar workout (editar ejercicios, descripción, etc)
```
PUT /workouts/{id}
Content-Type: application/json

{
  "description": "Chest Day Modified",
  "plannedDate": "2024-04-22",
  "completed": false,
  "exercises": [
    {
      "exercise": { "id": 5 },
      "sets": 3,
      "reps": 12,
      "weight": 25.0
    }
  ]
}

RESPONSE (200 OK): Workout actualizado
```

### 6. Crear workout (manual)
```
POST /workouts
Content-Type: application/json

{
  "description": "Manual Leg Day",
  "plannedDate": "2024-04-24",
  "user": { "id": 1 },
  "routine": { "id": 10 },
  "exercises": [
    {
      "exercise": { "id": 7 },
      "sets": 4,
      "reps": 8,
      "weight": 50.0
    }
  ]
}

RESPONSE (201 Created): Nuevo Workout
```

### 7. Eliminar workout
```
DELETE /workouts/{id}

RESPONSE (204 No Content)
```

## ⚠️ CÓDIGOS DE ERROR COMUNES

| Código | Mensaje | Razón |
|--------|---------|-------|
| 400 | Bad Request | Datos inválidos (email ya existe, password corto, etc) |
| 401 | Unauthorized | Email/password incorrecto en login |
| 404 | Not Found | Recurso no existe (User, Routine, Workout, etc) |
| 500 | Internal Server Error | Error en servidor (exception no manejada) |

## 🔄 FLUJO TÍPICO (Frontend → Backend)

```javascript
// 1. REGISTRO
POST /api/auth/register
Body: {name, email, password}
→ LocalStorage: setCurrentUser(user)

// 2. CREAR OBJETIVOS
PUT /api/users/{id}/goals
Body: {goalType, level, trainingDaysPerWeek}

// 3. GENERAR RUTINA
POST /api/routines/weekly/generate
Body: {userId, weekStart}

// 4. VER RUTINA SEMANAL
GET /api/workouts/user/{id}/week/{weekStart}

// 5. MARCAR COMPLETADO
PUT /api/workouts/{id}/mark-completed
Body: {completed: true}

// 6. VER PROGRESO
GET /api/sessions/compliance/user/{id}/week/{weekStart}
```

---

## 📝 NOTAS

- Todos los endpoints devuelven JSON
- Fechas en formato: YYYY-MM-DD (ISO 8601)
- Passwords se validan > 6 caracteres
- Los campos de User devueltos nunca incluyen password
- Si `autoGenerated=true`, la rutina fue creada por el sistema
- Si `ownerId=null`, el ejercicio es global (disponible para todos)
