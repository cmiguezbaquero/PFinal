## 📊 ARQUITECTURA ACTUAL

```
FRONTEND (Html/Js)
├── /users/users.html (Register/Login)
├── /goals/goals.html (Guardar objetivos)
├── /home/home.html (Dashboard)
├── /workouts/workouts.html (Ver rutina)
└── /shared/api.js (Llamadas HTTP)
        ↓
BACKEND (Spring Boot)
├── AuthController → UserService → UserRepository
├── RoutineController → RoutineService → ExerciseRepository
├── WorkoutController → WorkoutService
└── WorkoutSessionController → WorkoutSessionService
        ↓
DATABASE (JPA)
├── User (id, email, password, hasGoals, goalType, level, trainingDaysPerWeek)
├── Routine (id, name, weekStart, autoGenerated, workouts)
├── Workout (id, plannedDate, completed, exercises)
├── WorkoutExercise (id, exercise, sets, reps, weight)
├── Exercise (id, name, muscleGroup, ownerId, shared)
└── WorkoutSession (id, date, notes, workout)
```
