# Guia rapida

Workout Planner permite registrar usuarios, guardar objetivos y generar rutinas automaticas para entrenar.

Flujo basico:
1. Registro o inicio de sesion.
2. Guardado de objetivos y nivel.
3. Generacion de rutina semanal.
4. Visualizacion de workouts y sesiones.
5. Seguimiento de progreso.

Lo mas importante:
- El backend crea y guarda la rutina.
- El frontend muestra los datos y permite iniciar sesion.
- La generacion de ejercicios evita repeticiones dentro del mismo dia.
